# Whatsapp-Automation-App
A simple automation tool for sending scheduled WhatsApp messages.

**** Description****
WhatsAuto is a simple automation tool for sending scheduled WhatsApp messages.
Built with Python, this project demonstrates how to automate WhatsApp messaging for personal or business use.

It’s a beginner-friendly example of:

Task scheduling

Browser automation

Message handling
Features

* Send scheduled messages on WhatsApp...
* Simple and lightweight.
* Educational project for learning automation.
* Open-source and customizable.
  Tech Stack
  
Python 3
Selenium or PyWhatKit
Tkinter (for simple GUI)
